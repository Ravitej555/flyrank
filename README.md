# FlyRank ✈️

> Intelligent flight search, comparison, and utility scoring engine.

FlyRank helps travelers make smarter booking decisions by going beyond basic price comparisons. It analyzes total flight friction—balancing ticket costs, travel duration, layover stress, airline safety ratings, and estimated emissions into a single, intuitive **FlyRank Composite Score (0–100)**.

---

## Features

- **Multi-Dimensional Flight Scoring**: Evaluates itineraries on a balanced composite scale.
- **Customizable Preference Sliders**: Shift weights between budget, speed, and comfort.
- **Layover Friction Analysis**: Penalizes red-eye connections and high-stress tight transfers.
- **Carbon Footprint Metric**: Estimates carbon impact per passenger kilometer.
- **Responsive Modern UI**: Fast, clean user interface built with Next.js and Tailwind CSS.

---

## Tech Stack

- **Framework**: Next.js 15 (App Router, React 19)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Backend / APIs**: Node.js Route Handlers
- **Testing**: Vitest

## Quickstart

### Prerequisites
- Node.js (v20+ LTS recommended)
- npm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/Ravitej555/flyrank.git
cd flyrank

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.
